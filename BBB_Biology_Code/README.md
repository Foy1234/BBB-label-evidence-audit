# BBB heterogeneous-evidence analysis code

This repository contains a minimal public code release supporting the principal results and reported sensitivity analyses in the Biology manuscript “Heterogeneous Experimental Evidence Shapes Operational Blood–Brain Barrier Permeability Labels and Their Computational Evaluation”.

## Included scope

The release covers molecular standardization, parent-level consensus construction, the eight-view cross-dataset label audit, frozen evaluation splits, Morgan-XGBoost and GINE analyses, the auxiliary probabilistic evidence representation, uncertainty/calibration analyses, the independent NCATS PAMPA-BBB endpoint analysis, and the supplementary cleanlab, ChemBERTa, simulation, and provenance analyses. Manuscript-generation utilities, deprecated versions, SHAP/MMP exploratory scripts, bytecode caches, and unrelated legacy analyses are excluded.

Python source files are distributed without inline comments or docstrings. Scientific definitions and interpretation are documented in the article and Supplementary Materials.

## Project root

Set `BBB_PROJECT_ROOT` to the repository root. If it is not set, the directory containing `run_core.py` is used.

## Input layout

Place third-party data under:

```text
00_数据_原始/
  BBBP.csv
  B3DB_数据/
    B3DB_classification.tsv
    B3DB_regression.tsv
  NCATS_PAMPA_BBB_AID1845228.csv
  NCATS_PAMPA_BBB_AID1845228_properties.csv
  QSARDB_独立logBB/
```

Outputs are written under `05_复现工作区/` and selected supplementary summaries are mirrored under `02_结果/`.

## Data sources

- BBBP: https://deepchemdata.s3-us-west-1.amazonaws.com/datasets/BBBP.csv
- B3DB archived release: https://doi.org/10.6084/m9.figshare.15634230.v3
- B3DB repository: https://github.com/theochem/B3DB
- NCATS PAMPA-BBB, PubChem AID 1845228: https://pubchem.ncbi.nlm.nih.gov/bioassay/1845228
- Clark 1999 logBB, QsarDB QDB.199: https://doi.org/10.15152/QDB.199
- Abraham et al. 2006 blood-brain distribution data, QsarDB QDB.132: https://doi.org/10.15152/QDB.132

## Installation

Python 3.11.9 is recommended. Install `requirements.txt`. PyTorch CPU wheels may require the installation command provided by the official PyTorch distribution for the target platform.

## Principal analysis

```bash
python run_core.py
```

## Supplementary analyses

```bash
python run_supplementary.py
```

ChemBERTa requires access to the pretrained model used by the original analysis or an equivalent local cache.

## Minimum public-release boundary

The repository provides source code and the fixed analysis settings required to reconstruct the reported analyses from the cited third-party datasets. Raw third-party datasets, large caches, complete resampling distributions, and all generated molecule-level intermediate outputs are not redistributed; they can be regenerated by the included scripts.
